# 本地运营工作台与轻量 3D 前端

Vue 3 + TypeScript + Vite，版本 0.2.0。接口遵循 `docs/MVP_CONTRACT.md` 以及同目录的 OUTPUT、BUSINESS、AUTOMATION、INTEGRATIONS、TEMPLATES 契约。页面使用实际服务端记录，不内置演示商品、评论、头像或虚构的媒体在线状态。

## 开发与构建

使用 Node.js 24，在 `web/` 目录运行。npm 与 pnpm 均有锁文件；选定一种包管理器后不要混用：

```sh
npm ci
npm run dev
```

开发服务器监听 `127.0.0.1`；`/api`、`/output-api` 与 `/healthz` 默认代理至 `http://127.0.0.1:8080`。通过 `API_PROXY_TARGET` 更改本地代理目标。

```sh
npm run typecheck
npm test
npm run build
npm audit
```

轻量 3D 页可由主控制台同源提供在 `/avatar3d/`，也可使用仓库根目录的 `scripts/start-avatar3d.ps1` 或 `scripts/start-avatar3d.sh` 独立准备和启动。页面只处理本机 GLB 与音频，不自动调用云服务或发起直播。

构建产物位于 `web/dist`，由 Go 服务的 `WEB_DIST` 指向该目录并同源提供。无需外部字体、付费 UI 服务或第三方图标网络请求。

## 业务工作流

- 工作台口令认证，口令仅保留在当前页面内存；刷新、退出后重新登录。
- 创建与切换店铺；商品价格精确转换为整数分，编辑采用版本检查，支持历史查看与恢复为新版本。
- 活动的商品范围、优惠内容、价格、开始与结束时间、启用状态及历史查看。
- 品牌人格版本与恢复；知识和人工记忆的来源、店铺/商品/场次范围、有效期、删除及历史恢复。
- 话术模板 CRUD。仅允许 `{title}`、`{sku}`、`{price}`、`{stock}`、`{specs}`、`{description}`；应用时由服务端读取当前商品快照，创建待人工审核草稿，不调用 DeepSeek 或自动播报。
- 素材、音色、模型的授权与 SHA-256 档案。界面明确写明“档案记录，待联调核对”；保存档案不会修改外部模型或音色进程配置。
- 本地场次创建、暂停接管、恢复与本地结束；人工话术或 DeepSeek 草稿、人工批准、持久语音队列、音频试听、媒体派发及取消。
- 已审核任务的优先级、截止时间与单次定时派发；定时派发需独立输出端在线。未知派发不自动重试，重启不补播错过时间的计划。
- DeepSeek 每分钟与 UTC 日限额、全局并发和保守 token 预留；成功用量与未知用量分别显示。
- 人工费率与功率成本估算。未设置费率使用 `null`，不冒充零成本；月预算仅记录，生成限额在独立页面配置。
- 实际服务诊断、关键词或配置的本地 BGE 检索核对。
- 淘宝本地场次映射、明确标为回放来源的评论入库及去重、显式生成待审核稿；平台商品先预览、人工核对后保存为新商品，不静默覆盖。
- 显式弹卡与实际状态上报保留同一 `request_id` 和固定参数，网络结果不明时不得自动换号重发；请求编号在运营页导航间保留，退出或刷新页面后清除。
- 质量核验为人工记录，所有项目默认未通过；未保存档案不会显示成实测通过。

服务“已配置”与真实媒体“在线”分别显示。`sent` 只显示“上游已接收”，不能证明观众已听到。价格、版本、执行批次和时间边界由后端在每个状态转换前再次核验。

## 独立 OBS 输出

`/output` 是独立入口，与管理登录和业务组件分开加载。运营台在选定本地场次下签发一次可见的专用链接，格式为 `/output#token=...`。其中只有窄权限输出 token，没有工作台 APP_TOKEN。接收页不使用浏览器持久存储、不使用 cookie，也不请求管理 API。

1. 在工作台签发独立输出链接，配置画布宽高与适配方式。
2. 将链接添加为 OBS 浏览器源，并使用一致的宽高。也可在独立浏览器页面核对连接。
3. 一个场次只允许一个接收者。已有有效租约时，另一页面不会抢占原输出。
4. 接收页建立 recvonly WebRTC，不采集摄像头或麦克风。真实 Peer 连接、存活音视频轨道和有声播放均就绪后才报告心跳；自动播放被阻止时明确提示。
5. 运营页面关闭或导航不会关闭独立接收页；关闭 OBS 源或独立页会停止接收。
6. 暂停立即清空画面并关闭 Peer；恢复后重新协商。结束或撤销使 token 失效并停止重连。心跳过期后后端禁止派发。

输出画布分辨率不会提高模型的原生嘴部细节。“输出端在线”是接收页报告的传输状态，不能证明 OBS 原生采集、淘宝实际开播或观众端播放效果。

未启用独立输出时，仍可使用依赖当前运营页面的管理预览；离开工作台会关闭该 Peer。启用独立输出后管理页不创建第二个预览 Peer，发送按钮依据服务端租约状态开放。

音频预听使用带 Bearer 的 `fetch` 获取 Blob，关闭时撤销临时 URL；口令不放进音频 URL。本地语音不可用时不自动调用其他付费供应商。

## 测试与证据边界

Vitest 使用隔离的接口和 WebRTC 替身，覆盖金额、版本/批次失效、错误表单保留、窄权限路由、心跳条件、暂停清空、授权撤销、自动播放失败、重复接收者、同一平台请求编号保留等软件行为。它们不证明模型、GPU或实际淘宝直播已经验收。

`tests/browser/business.cjs` 使用真实 Chromium、Go API 和独立 PostgreSQL 数据库，操作真实 UI 进行资料 CRUD、历史恢复、模板应用、限额、调度、评论回放、检索和缺配置失败检查，并保存桌面与 390px 页面截图。该脚本清空外部模型、媒体和淘宝配置，不调用付费 API；测试记录明确命名为 UI 验收记录。

`tests/browser/transport.cjs` 单独验证真实浏览器 WebRTC 传输与租约，媒体源是明确标注的测试画面和测试音频。它验证传输控制，不产生数字人口型、真实 CosyVoice、OBS 原生采集或淘宝播出的质量结论。两个浏览器脚本需要不同的可丢弃数据库，不能共用正在运行的业务数据库。
