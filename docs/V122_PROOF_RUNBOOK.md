# yunchuang_v122 第一阶段验证操作手册

## 本阶段最终得到什么

使用一段人物视频、一段参考声音、参考声音逐字稿和一段新话术，创建本地人物与音色，生成新的WAV，并用该WAV驱动人物输出可播放MP4。本阶段不登录直播平台；MP4效果通过后才进入OBS和直播输出阶段。

录制和使用人物、声音前，必须取得素材权利人明确授权。素材、人物资源、声音资源、日志和结果只保存在验证电脑，不进入GitHub。

## 实施人员需要准备

1. 可正常使用的摄像头，或20–60秒正面单人视频；建议1080p、固定机位、半身、稳定光线、无遮挡。
2. 可正常使用的麦克风，或10–15秒清晰参考WAV/MP3；单人、无背景音乐、少混响。
3. 参考声音逐字准确文本。
4. 数字人要说的一段新验证话术。

## Mac制作离线包

选择一个全新的空目录作为目标，执行：

```bash
V122_RUNTIME_SOURCE=/Users/apple/claudelife/shuziren/yunchuang_v122 \
V122_PROOF_DESTINATION=/path/to/new/v122-minimum-proof \
make build-v122-proof
```

构建器拒绝覆盖非空目录、拒绝符号链接，并生成逐文件SHA-256清单。生成目录含商业运行包和模型，不得上传GitHub。

## Windows操作

1. 将整个`v122-minimum-proof`复制到短路径，例如`D:\v122-proof`；建议至少保留80GB磁盘空间。
2. 可先双击`01_环境检查.cmd`查看独立报告；双击`00_开始验证.cmd`时也会自动执行完整性、磁盘、NVIDIA驱动、Torch CUDA、ONNX CUDA、FFmpeg和ffprobe检查，未通过时不会启动生成页面。
3. 环境通过后浏览器自动打开本地页面。
4. 点击“开始摄像头录制”，录完后预览并确认；设备不可用时点击“选择已有视频”。
5. 点击“开始麦克风录音”，录完后试听并确认；设备不可用时点击“选择已有WAV”。
6. 填写参考录音逐字稿和新验证话术，点击“检查并开始生成”。
7. 页面依次显示素材检查、人物创建、音色建立、语音生成、口型驱动和MP4合成。
8. 试听新WAV并播放最终MP4，人工评价人物、声音、口型、闪烁和音画同步。

## 通过标准与故障定位

- 素材转换失败：`MAT_CONVERT_*`，重新录制或选择合规文件。
- 人物创建失败：`V122_AVATAR_FAILED`，检查人脸可见性、CUDA和模型。
- 声音建立失败：`V122_VOICE_FAILED`，检查参考音频和逐字稿。
- 语音生成失败：`V122_TTS_*`，检查音色资源和语音模型。
- 口型驱动失败：`V122_DRIVE_*`，检查人物资源、WAV和GPU显存。
- MP4失败：`V122_MP4_*`，检查FFmpeg输出和磁盘空间。

程序退出码为零不等于效果通过。最终MP4必须可以播放，且人物可辨识、声音可接受、口型和音画同步由实施人员确认。Windows真实执行前，功能矩阵只能标记为静态验证通过。

环境与完整性报告保存在`reports\preflight`。素材转换后会用ffprobe再次检查视频时长、分辨率、帧率、WAV时长、声道和编码；最终MP4必须同时存在视频流和音频流。

需要停止本工具时双击`99_停止验证.cmd`。该脚本只停止PID、可执行路径和创建时间都与登记记录一致的本工具进程，不结束系统中的其他Python进程。
