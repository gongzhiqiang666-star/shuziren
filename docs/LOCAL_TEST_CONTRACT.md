# v0.2 本地测试交付范围

本次目标是使一台本地机器上的业务、媒体控制和外部接口适配具备完整测试入口。保持淘宝单平台、DeepSeek 唯一收费 AI 接口、Go/Gin + Vue + PostgreSQL、CosyVoice3 + LiveTalking/MuseTalk 本地媒体链。安装完成、协议测试通过、真实模型运行、真实淘宝播出是四种不同证据，不能互相替代。

## 必须覆盖的功能

| 模块 | 本地可操作行为 | 关键验证 |
| --- | --- | --- |
| 商品、活动 | 版本、历史、恢复、价格/库存/时间范围 | 修改和自然到期使旧任务失效 |
| 人格与记忆 | 风格、来源、范围、有效期、版本与恢复 | 表达不能覆盖事实，跨店/越界记忆不进入上下文 |
| 话术模板 | 用当前商品字段展开成待审核草稿 | 不执行表达式，同一快照渲染并再次核验，展开内容仍需人工核对 |
| 知识检索 | 关键词基础模式；可配置 BGE 本地语义检索、向量缓存 | 模型缺失报告不可用；不冒充已完成语义检索 |
| 审核与播报 | 人工审核、持久化队列、优先级/截止时间、接管/恢复 | 接管后的旧批次不能迟到播报，未知派发不自动重试 |
| 费用与预算 | 成功和未知用量记录、运营者费率、预算/并发限制 | 无费率不是零成本，超时不是免费 |
| 素材与缓存 | 授权记录、版本与哈希、缓存隔离 | 档案不等于外部进程已切换素材 |
| 独立输出 | OBS 浏览器源、窄权限可撤销链接、真实 WebRTC、单接收者租约 | 运营页面关闭后继续连接；过期心跳不能派发 |
| 淘宝适配 | TOP 签名、直播间查询、商品读取、弹卡、统计上报、TMC consume/confirm | 幂等入库后确认；不能将回放标为真实平台消息 |
| 运维与质量 | 配置诊断、备份恢复、安装脚本、口型语料、校准及持续测试 | 记录真实测量结果；缺少模型/素材/授权有明确状态 |

接口细节分别见 [OUTPUT_CONTRACT.md](OUTPUT_CONTRACT.md)、[BUSINESS_CONTRACT.md](BUSINESS_CONTRACT.md)、[INTEGRATIONS_CONTRACT.md](INTEGRATIONS_CONTRACT.md)。调度契约由后端与前端共同冻结。

## 本地测试准入

1. 后端单元测试及真实 PostgreSQL 事务/迁移/并发回归通过。
2. 前端类型检查、构建、组件回归及实际浏览器工作流通过。
3. 未配置付费密钥、模型或淘宝权限时，能够完成业务资料/审核/回放测试，外部动作明确拒绝。
4. 配置模型与授权素材后，执行真实 TTS → WAV → WebRTC → OBS 的测试，不用测试替身填质量结论。
5. 安装、备份恢复及故障恢复有可运行入口；启动不会重播不确定任务。

## 保留为目标机器验收的项目

本地软件测试不会产生目标显卡的 FPS/显存结论、人物的真实口型/牙齿细节评分、8 小时稳定性结论、淘宝账号权限或实际播出成功结论。这些需在目标机器上用授权人物/声音、模型文件和已获权限的淘宝应用运行。开发完成后在 `IMPLEMENTATION_STATUS.md` 逐项记录实际证据与仍需实机验证的项。
