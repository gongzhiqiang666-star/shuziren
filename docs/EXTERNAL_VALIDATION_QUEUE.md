## 执行规则

1. 每次只恢复条件已经齐备的队列项，并回到“对应任务”列的原编号验收，不新建较低标准。
2. 账号、密钥、Cookie、客户素材、声音、模型和商业程序不得提交；Git 只保存脱敏结论、哈希、命令和结果摘要。
3. 真实付费、平台发布、采购、投放或对外动作必须先固定费用和授权范围；夹具只验证协议，不替代真实业务结果。
4. 阻点重复出现时更新同一队列项，不反复重试；其他无依赖任务继续推进。
5. 一项完成后保留历史证据，并在功能矩阵、阶段计划和本表同步状态。
