# CNT-011 IP 视频发布契约

验证日期：2026-11-14

## 发布前门禁

- 平台仅允许随包上传器真实支持的 `douyin`、`kuaishou`、`tencent`、`xiaohongshu`，去重并拒绝未知值。
- 视频必须存在且非空，计算 SHA-256，并在发布计划返回前通过 FFprobe 视频轨门禁。
- 标题 1～100 字符；标签最多 20 个、每个最多 30 字符；封面必须存在。
- 账号名仅允许 1～80 个 Unicode 单词字符、数字、下划线或连字符，拒绝 `.`、`..` 和路径形式，避免外部上传器的 cookie 文件路径逃逸。
- 定时发布必须是可解析且晚于当前时间的时间；立即发布统一为 0。

## 预演、幂等与审计

- `dry_run=true` 仍执行媒体及全部字段校验，只返回发布计划，不导入上传器、不登录、不上传。
- 未显式提供请求号时，由视频 SHA-256、标题、标签、平台、账号、时间和封面形成稳定请求号。
- 同请求号已有成功结果时直接返回 `already_published`，避免页面重试或网络响应丢失造成重复发帖；只有 `force_republish=true` 才允许再次执行。
- 项目保存标准化平台/账号/标题/标签/时间、请求号、完整发布计划和上传器逐平台结果；上传器返回结构不合法时明确失败。

## 自动验证

`tests/test_ip_publish.py` 5 项通过：标准化与稳定请求号、未知平台/路径账号/空标题/过量标签拒绝、未来时间和封面、API 预演不加载上传器、相同成功请求不重复调用上传器。

本轮没有授权对外发布，因此没有触发任何第三方平台动作。真实登录、扫码、Cookie 失效、草稿/立即/定时发布、部分平台失败和重试必须在测试账号上逐项确认，届时再提升 Windows/端到端状态。
