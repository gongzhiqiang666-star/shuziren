日期：2026-11-14。任务：X04-01 完成；X04-02 条件缺失。

## 候选边界

- 仓库现有 `recovered/cosyvoice.py` 调用 DashScope HTTP/WebSocket，属于 MED-009 在线能力，不是本任务评测的本地开源引擎。
- 本地候选固定为官方 `FunAudioLLM/CosyVoice` 主分支提交 `074ca6dc9e80a2f424f1f74b48bdd7d3fea531cc`，首选模型 `FunAudioLLM/Fun-CosyVoice3-0.5B-2512`。如果该组合在 Windows 失败，才以同一协议补测 `CosyVoice2-0.5B`，不得混合结果。
- 源码仓库为 Apache-2.0。模型权重、参考音、字体/文本前端等资源分别核对其模型卡和授权；未完成该检查前不得进入发行包。
- 使用独立 Python 3.10 环境和独立模型目录，不修改已验证的 IndexTTS/OmniVoice/ZipVoice 媒体环境，不提交源码镜像、权重或参考音。

## 同条件输入和冻结门槛

与当前 IndexTTS 基线使用同一 RTX 3060、同两条已授权参考音和同一组新文本；至少覆盖商品品牌词、年份/价格/容量/折扣、中英混合、短句、约 60 字句和约 300 字段落。每条保存输入摘要、参考音摘要、输出 WAV 摘要、采样率/声道/时长、冷/热启动、首块/完成耗时、RTF、进程 RSS 与整卡显存。

进入 X04-03 的必要条件：

1. 全部真实生成产物非静音且可完整解码；文本自动回归沿用 V03 的 CER 不超过 0.15，双参考音可区分性沿用目标参考余弦比另一参考至少高 0.05。
2. 人工检查品牌、数字、单位、中英切换、句首句尾和身份保持，无阻断错误；自动分数不能替代人工听感。
3. 热态 RTF 小于 1；首块、完整耗时和峰值资源逐项与 IndexTTS 同批报告。候选只有在音质、响应或维护性至少一项有明确收益且其余项不退化时才进入产品队列。
4. 失败、取消后进程和显存可恢复，第二次请求可成功；缓存键包含模型版本、参考音、文本和推理参数。
