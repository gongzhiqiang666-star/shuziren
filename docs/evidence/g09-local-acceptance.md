# G09 广告、预算与受控经营动作本机验收

日期：2026-11-14

## G09-01 费用与归因口径

投放账单绑定商品、来源、完整日期窗口、活动、素材和非负整数分支出；归因口径允许未知。相同主键的账单更正覆盖当前值但不会误改其他素材或店铺。费用零与缺失分开，未登记归因时不计算或宣称精确 ROI。

## G09-02 预算与内容建议

预算预览读取当前商品版本、已核对且未过期的库存事实和当前账单，生成带日上限、总上限、起止时间、活动、素材和依据的草稿。旧账单、旧商品版本或库存依据到期后，方案标记待重审，审批被拒绝；不能用预测值绕过实际账单和库存。

## G09-03 小范围受控执行

方案只有草稿、已审批和已暂停的本机状态。审批记录明确对象、时间和额度；暂停可重复调用但操作日志只保留一次有效状态变化。当前系统不调用平台改预算、改价或上下架，因而本机“已审批”只代表授权记录，不代表第三方动作成功。

## G09-04 增量与回退

对照要求同一商品、来源、活动和素材的两个完整、不重叠窗口。返回各窗口总支出、覆盖天数和日均支出；归因口径缺失或不同保持不确定，不把自然流量或其他活动归功于方案。暂停是当前可验证的回退状态，真实平台恢复仍需外部联调。

## 验证与边界

账单更正→预算预览→审批→商品/库存/账单变化失效→暂停→窗口比较专项通过，跨店账单和方案隔离专项通过；同提交链全仓 473 项回归通过。

真实广告账号、平台预算执行、平台回执、生产回退、订单归因、退款滞后和增量效果均为外部条件。取得账号和明确授权前不发送动作；真实数据不可比时结论保持不确定。
