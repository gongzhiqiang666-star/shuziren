# V05-02：常驻特征与逐句帧生成

2026-11-11，本机RTX3060，随包Python/WeNet/UNet、TensorRT FP16＋NVENC。本项通过常驻模型与逐句驱动范围；V05整关仍未放行。

原WeNet对每次输入独立提取特征，短输入还会补静音。没有直接把交接小段分别送入模型：SpeechAssembler在磁盘还原一条完整语音，核对段序号、场次、任务、采样偏移及完整PCM SHA后交付。新的原PCM指纹贯穿分段和队列，原WAV SHA另外保留，避免把重建容器头部变化误认为音频改变。

LiveAvatarClient启动自有JSON-lines worker，常驻一个WeNet模型和一个UNet会话；每次新语音到达后才计算该句特征，再最多4帧一批生成并交给编码器。形象往返序列跨句继续。没有预计算整场，也没有缓存整句图像；当前采用批次迭代器的自然背压，尚无定时播放预缓冲。统计列表每句清空，避免随着句数增长。

父进程核对结果场次、任务、PCM指纹、输入/输出路径与文件SHA；错误或停止结果不能接受。控制响应限长，超时回收自有进程树。媒体检查失败清理本次输出。已经收到最终响应的空闲worker通过stdin EOF退出；活动任务取消仍回收进程树。
