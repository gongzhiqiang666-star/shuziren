# MED-007 IndexTTS 长文本验证

验证日期：2026-11-14

## 实现

- 超过 300 字的输入按句末、逗号或安全硬边界分段。
- 每段先写入自有临时 WAV，校验声道、采样位宽、采样率和编码一致后按 PCM 顺序合并。
- 完整输出和变速输出均临时写入后原子发布；分段失败会清理全部半成品且不记录缓存。
