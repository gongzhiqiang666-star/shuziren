# G05 内容生产、复用与分发本机验收

日期：2026-11-14

## G05-01 内容源与资产

历史口播绑定商品/话术版本、分段、采样区间、受管 WAV 摘要、音色及授权、TTS 引擎和模型身份。商品更新不改写历史，当前复用提示重新核对。音色授权和模型身份分别见 `g05-voice-authorization-provenance.md`、`g05-model-identity.md`。

## G05-02 内容组合

有效口播可生成短视频文案、重新合成数字人成片、导出零起点 SRT，并将 BGM 复制到受管目录绑定摘要。原音频、BGM、形象、文案和视频任务均按版本/摘要校验，越界、篡改或输入变化拒绝。既有真实 CUDA 成片和 Chrome 字幕下载留样仍在，发布准备包可完整解压和解码。

## G05-03 排期与发布

排期绑定当前人工审阅文案、账号、受众、含时区发布时间和渲染资产摘要。改稿、撤回或商品来源变化后旧排期/包拒绝；发布回执按账号和平台作品编号唯一，重试幂等，并发登记只接受一个结果。当前本机仅登记回执，不冒充平台实际发布。

## G05-04 结果与停止复用

场次报告显示改稿率及分母、未知改稿数量、已登记/缺失制作耗时和人工基线配对差异。草稿可停止复用，停用后页面和接口均拒绝继续排期。没有平台曝光、播放、转化和退款数据时不计算内容效果。

## 验证与边界

本轮 6 项专项通过，覆盖受管音频与 Range、版本绑定渲染输入、BGM、确定性发布包和下载委派。真实留样 `g05-live-content-render-real-08`、`g05-render-subtitle-chrome-01`、回执并发、来源写竞争和报告覆盖记录均存在。当前源码链全仓 473 项通过。

仍需真实平台发布/回执、人工口型与声音同步、图形剪辑工具导入、多语言成片、真实素材授权抽检，以及观察窗口内内容效果。IndexTTS 许可仍未核实，ZipVoice/OmniVoice 尚未进入自有媒体包。
