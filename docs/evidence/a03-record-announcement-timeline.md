# A03-04 实拍报时时间轴

## 受控输入

本机 FFmpeg 生成 2.000 秒、320×240、25 fps 的 H.264/AAC 视频，原声为 440 Hz；另生成 0.4 秒、880 Hz 的报时替代音。使用产品 `_extract_real_shot_audio`、`_mix_real_shot_audio` 和 `_mux_real_shot_video` 替换 0.5～1.2 秒区间。

## 缺陷与复测

首轮 AAC 解码后的 WAV 为 2.020 秒，原封装没有最短轨截止，输出容器被延长为 2.020 秒，不通过。封装增加 `-shortest` 后用同一输入复测：输出容器 2.000 秒、视频 2.000 秒、音频 1.997007 秒，末端轨差约 3 ms，未改变视频时间轴。

录播生命周期 7 项及恢复五关通过。该证据覆盖受控成片时长和双轨存在；真实 TTS 听感、插播接收端连续性及长稳仍按后续验收。
