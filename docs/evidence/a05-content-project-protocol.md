# A05-01 文案工具与项目协议验证

日期：2026-11-14。

## 已验证范围

- 控制台 LLM 使用显式 endpoint/model/key，覆盖完整返回、空返回、401/500、超时、响应中断、取消、重启中断和商品并发修改；失败不保存半条话术、不把凭据写入状态。
- 目标语言重试使用同一显式配置；恢复五关继续覆盖翻译、改写、禁词、随机话术选项及特殊变量的原接口契约。
- 标题标准 JSON 支持标签去重与 `#` 规范化；轻微破损的旧格式继续兼容。字符串标签、嵌套标签和非文本标题明确失败，不再把字符串逐字符保存成标签。
- 商品/话术项目覆盖 CRUD、版本冲突、跨商品隔离、并发编辑、选择失效、重开持久化和 v1 数据库迁移；旧话术、父子改稿和未知字段不丢失。

专项结果：控制台 LLM 11 项、项目存储 23 项、标题异常输出 4 项、真实 LLM 门禁 3 项，共 41 项通过；恢复基线五关通过。第一次联合测试错误使用不存在的 `tests` Python 包路径，3 个模块未执行，不计通过；改用 discover 后分别复跑通过。
