# G05-01 音色授权追溯

日期：2026-11-14

## 完成范围

- 音色登记新增 `未登记`、`本人录制`、`已获本人同意`、`已取得许可` 四种授权类型，并可填写不超过 500 字的授权书或内部素材编号；界面明确禁止填写密钥。
- 文件导入与本机录音使用同一授权字段，音色列表显示授权类型和依据。
- 音色数据库从 v1 原位升级到 v2。历史记录保留，新增字段默认 `unknown`，不会把旧音色臆测为已经授权。
- TTS 任务冻结授权快照；口播完成后写入口播来源 `speech_provenance`。后续改变音色登记不会改写历史口播证据。
- 场次口播来源页面同时显示参考音/文本摘要、授权类型与授权依据；已归档 WAV 的摘要和大小仍由原有链路绑定。

## 验证

- 真实 FFmpeg 音色规范化、授权字段、非法类型、v1→v2 迁移、篡改和录音临时文件：6/6 通过。
- TTS 状态、输入变化、引擎切换、主播/助播音色绑定和任务恢复：12/12 通过。
- 直播语音入口快照、引用篡改、商品版本绑定、队列和清理：10/10 通过。
- 音色 HTTP 导入、选择、预览及授权字段：1/1 通过；前端脚本语法通过。

## 未完成边界

本项只完成音色素材的授权关联和历史口播快照。授权文件本身不上传仓库，系统也不会判断合同法律效力。模型权重版本/许可身份、真实商家素材抽检和人工听感仍按 G05-01 后续子项验证。
