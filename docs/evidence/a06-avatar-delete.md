# A06-03 形象资源安全删除

验证日期：2026-11-14。

形象库原有导入、枚举、校验和选择，但没有删除能力。本次新增：

- 删除前完整校验 ID、清单和逐文件摘要；当前选中形象拒绝删除，避免直播/生成引用失效。
- 目标必须是形象根目录的直属 UUID 目录；先在同一根目录用 `os.replace` 改名为随机 `.deleting-*` tombstone，使资源立即不可再用。
- 随后在数据库事务中删除唯一记录；事务失败时将 tombstone 原子恢复到原目录。
- 数据库已提交但物理清理遇到 Windows 占用时返回 `cleanup_pending`，不伪装成目录已删除；下次初始化只扫描根目录直属 `.deleting-*` 并重试，目录联接/越界目标不递归删除。
- 本地控制台增加管理员删除 API 和未选中形象列表；切换选中项后重读删除候选。

`tests/test_avatar_store.py` 8 项通过，其中新增选中保护/未选中删除、SQLite trigger 注入失败恢复、目录占用后重启清理。控制台 HTTP 单链通过两形象导入、选中保护、删除另一形象和列表重读；前端语法通过。真实大形象文件占用、直播运行中删除和浏览器点击继续待验。
