# CNT-007 IP 多版本改写事实门禁

验证日期：2026-11-14

## 实现

- `rewrite_ip_script` 对 LLM 返回的每个 `versions[].text` 逐一执行统一数字/价格事实门禁。
- 任一版本出现原文不存在的数字或无依据价格，整次改写失败；不会只返回第一个安全版本、把问题版本藏在列表中。
- 兼容字段 `rewritten_text/text` 形成的 fallback 成片稿同样校验。
- 校验发生在项目保存之前，因此失败结果不会写入 `rewritten_script` 或 `rewrite_versions`。
