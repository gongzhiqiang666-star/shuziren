# V03-02a 独立音色导入与规范化

2026-11-10，实现scripts/voice_store.py。音色保存到明确数据目录下voices/UUID，数据库登记名称、参考文本、音频/文本SHA256和时长；声音根目录与原运行包隔离。读取或选择时核对内容指纹，文件缺失/替换明确失败，不默默回退其他音色。

导入使用真实FFmpeg解码，输出单声道24kHz/16bit PCM WAV并配对ref_text.txt。当前导入门槛为音频1～30秒、输入最多100MiB、规范化均方根不低于0.001（归一化满幅），解码超时60秒。只解码最多31秒作上限检查，超过30秒拒绝，不把截断内容当完整参考音；不自动切除台词或补造对应文本。此门槛是媒体输入校验，不证明有声文件必为清晰人声或能克隆。

失败时仅删除本次生成且已检查父路径的UUID目录，源文件不删除/覆盖。成功登记后保留文件。进程异常被强制终止时的未登记目录回收尚未实现；未登记目录不会被列为可选音色。

## V03-02c 录音制作实现与自动化

新增VoiceRecorder浏览器控制器，借鉴既有proof录音的getUserMedia/MediaRecorder/释放轨道流程。支持请求权限、录制、30秒自动停止、试听、放弃、保存；离开页面或退出时停止轨道并清空预览URL。授权请求晚到、旧onstop回调晚到均通过代次检查隔离，不能停止新录音或生成旧预览。

保存时使用最多512KiB的base64录音请求，仍受服务端1MiB请求上限和Origin/会话校验约束。原始录音写入自有目录生成的临时文件，走同一真实FFmpeg规范化及指纹登记，finally清理临时文件；不把浏览器Blob当成已验证WAV。

本轮4项Node录音控制器测试通过（使用可控MediaRecorder/轨道替身，只证明状态和迟到清理逻辑）；5项真实FFmpeg媒体测试通过（新增实际WebM/Opus转PCM及坏录音清理）；18项控制台测试通过（新增录音请求成功、坏base64拒绝及临时文件不存在），无相关skip。两个JS文件语法检查及diff检查通过。

当前录音UI已实现但尚未真实浏览器/麦克风验收，未自动接受浏览器麦克风权限，未声称录到了真人。下一步仍是02c实机录制、停止/放弃/保存、设备及权限异常验证，再决定音色制作关卡是否放行。
