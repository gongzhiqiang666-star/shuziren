# G04 直播运营副驾本机验收

日期：2026-11-14

## G04-01 观察与边界

当前规则覆盖轮播/插播故障、普通口播队列满、设备欠载、连续口播静音、商品事实到期、已核对零库存、重复问题和班次到时。每项绑定场次、商品或输出事件；未知库存不触发，空闲静音不算故障，跨场次和超时间窗的重复问题不合并。

## G04-02 证据型建议

建议保留触发原因、时间、商品/话术或最近答复编号。故障恢复、队列释放、音频恢复或事实变化后提醒消失，相同当前事件不重复刷屏。专项确认只报告当前明确故障，历史或已恢复状态不会继续出现。

## G04-03 受控执行

提醒可人工确认、撤销再确认，状态变化写场次动作日志；相同控制修订去重。人工接管优先，接管或场次变化期间未完成的回复被丢弃，不能迟到播出。定时换班只在商品边界切换，保持绑定商品和音色。

## G04-04 验证边界

本轮 5 项专项通过：当前故障、控制去重、边界换班、连续静音恢复、接管/场次变化丢弃迟到回复。已有 Windows 实播记录覆盖 20 次班次切换，且前期虚拟设备链证明接管恢复不破坏短时输出。

本机 PCM 和发送队列只能证明应用送出的数据，不能证明观众端实际有声；运营建议触发的平台切品、真实误报/漏报、采纳率、操作时间和长稳仍需真实直播试点。没有平台授权时不执行切品动作。
