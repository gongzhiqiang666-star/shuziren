# LIV-007 淘宝登录、弹幕与商品同步

验证日期：2026-11-14

## 本轮修复

- 自有淘宝弹幕采集不再把单一 Playwright 浏览器会话当作整个采集器生命周期。页面、context 或浏览器断开后，先完整 `shutdown()` 旧控制器，然后使用同一 storage state 创建新会话。
- 重连采用 0.25～10 秒有上限指数退避，停止事件可在退避期间立即结束。
- `TaobaoLoginRequired` 不进入重连循环，直接返回“登录已失效”，避免无人值守时重复刷新验证码或触发风控。
- 商品同步入口除登录失效外，现在也把页面升级、网络、解析和超时异常转换为统一的 API 错误结构，不再逃出 JS API 边界。

## 验证

`tests/test_taobao_capture_lifecycle.py` 7 项通过：

1. 登录等待按设定截止时间退出，且支持轮询间取消。
2. 商品 ID 优先从标签提取，不误用商品名中的年份数字。
3. 控制页只在 Playwright 所属工作线程访问。
4. 初始快照和恢复后快照不重放旧评论。
5. 浏览器断开后新会话使用同一 storage state，收到新评论后可正常停止，两个控制器均已回收。
6. 登录失效只尝试一个会话并传递明确异常。

完整恢复契约保持 128/128 通过，同时覆盖淘宝讲解循环、商品动作、控制页自愈、点品和 AI 场控调用契约。

## 边界

本轮没有使用真实淘宝账号或对外执行商品弹卡。当前账号登录、扫码/验证码、真实商品列表、页面升级、弹卡和风控仍需在获授权的直播间验收。
