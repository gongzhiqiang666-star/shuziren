# A07-03 版本切换前数据备份

日期：2026-11-14

## 完成范围

- 非首次部署在候选版本健康检查通过、`active.json` 切换之前，为整个共享 `data` 创建独立备份。
- 普通文件逐项复制并核对复制期间源 SHA-256 未变化；SQLite 使用在线 backup API 生成一致快照并执行 `PRAGMA integrity_check`。
- 备份包含主店及 `data/shops` 下各店铺的配置、商品、话术、音色、形象和业务记录；仅排除运行锁及 SQLite WAL/SHM 临时伴随文件。
- 拒绝数据目录或子目录中的链接/Windows 重解析点，防止备份越界。
- 备份先在 `backups/.backup-*` 暂存，全部成功后原子改名；清单记录切换前后提交、时间、相对路径、类型、大小和 SHA-256。
- 备份失败时不调用 `write_active`，当前版本指针保持不变。

## 验证结果

- 控制台包专项 15 项通过。
- 新增真实普通文件、音色子目录和 SQLite 数据库备份；清单逐项复算一致，修改源文件后备份不变。
- Windows 首轮暴露 SQLite 上下文未关闭文件句柄、无法原子改名；已改为显式关闭源和目标连接，复测通过。
- 故障注入磁盘错误时，版本指针写入调用为零。

本子项完成可验证备份和“备份失败不切换”。从指定备份做受控恢复、数据架构门禁及真实 deploy→rollback→restore 流程继续在 A07-03 后续子项完成。
