# G05-01 TTS 模型身份与许可快照

日期：2026-11-14

## 实现

- 新增独立模型身份工具，支持 IndexTTS、ZipVoice 和 OmniVoice。构建时递归枚举真实模型目录，拒绝链接/重解析点和越界文件，忽略 macOS `._` 资源分叉文件。
- 清单记录引擎、提供者、模型根、每个文件的字节数和 SHA-256、文件集合聚合摘要，以及许可状态和依据；采用同目录暂存、`fsync` 和原子替换。
- `verify` 重新枚举和散列全部实际模型文件，新增、缺失、大小变化或内容变化均失败。
- TTS 每次提交前读取当前清单，将模型集合摘要、清单摘要、引擎、提供者和许可快照写入任务；直播口播完成后继续冻结到 `speech_provenance`，页面可查看。
- 没有清单的兼容环境明确记录 `unregistered`，不会把路径、目录名或文件时间冒充模型版本。清单损坏会阻止新 TTS 管理器启动。

## 许可与其他引擎边界

当前没有可审计的 IndexTTS 许可文件或内部审查编号，真实清单保持 `unverified`，因此只完成技术身份追溯，不能据此宣称许可放行。ZipVoice 和 OmniVoice 目前只存在于授权参考包，未向其中写入清单；待它们进入自有独立媒体包后分别构建、复核并登记可靠许可依据。模型和清单均不提交仓库。
