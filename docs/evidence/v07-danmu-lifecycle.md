# LIV-005 弹幕采集生命周期

验证日期：2026-11-14

## 修复

- 弹幕采集状态由专用可重入锁保护，工作线程及页面启停不再无同步地交叉修改引用。
- 手动停止会先从管理器切断 capture/callback/worker 状态，再尝试关闭外部采集器和等待线程。即使采集器 `stop()` 抛出异常，也会返回失败详情但不会永久卡在“采集中”。
- 采集消息流自然结束或连接异常时，工作线程会尽力关闭采集器并清空自己的管理状态，下一次启动无需重启应用。
- 启动过程中任一步失败都会尽力停止已创建的采集器并清理半初始化状态。

## 验证

- `tests/test_danmu_manager_lifecycle.py` 2 项通过：空流自然结束后重启、迭代异常后重启，以及 stop 异常时的状态断开和诊断保留。
- PDD 动态端口、URL 门禁、消息规范化和帧上限 7 项回归同时通过。
- 完整恢复契约保持 128/128 通过；其中包含快手消息协议、淘宝轮询生命周期、Shopee 页面状态/动作和直播协议审计。

## 边界

上述证据证明代码生命周期和已固定协议样本，不等于各平台当前真实账号可用。抖音、淘宝、快手、Shopee 和 PDD 的登录、真实直播间、协议升级、掉线重连与风控仍待授权平台验收。
