# A07-03 本机发布生命周期组合验证

日期：2026-11-14

## 验证方法

新增 `scripts.validate_release_lifecycle`，要求未使用的新目录，并使用真实 Git 提交构建两个完整源码 ZIP。验证不替换函数、不伪造健康检查，依次执行：

1. 构建基线提交 `7d6a67494afd9520783ff2a338d9acf3972b77d6`。
2. 构建目标提交 `71236996a58602bb1b655ff434b4586668a7b1ac`。
3. 首次 deploy 基线包，核对当前/上一版本指针。
4. 写入真实配置、商品、审核话术及商品/话术选择状态。
5. deploy 目标包，经过候选 HTTP 启动、`/api/state`、受控退出和升级前备份。
6. rollback 回基线包，再次经过候选健康检查并生成回滚前备份。
7. 修改当前端口和商品内容，再从升级前备份执行 restore-data。
8. 核对配置、商品、话术选择恢复，应用版本仍停留在回滚后的基线。
9. 核对恢复前临时修改完整保存在自动生成的安全备份中。
