# CNT-003 翻译目标语言与数字保真门禁

验证日期：2026-11-14

## 本轮修复

- 非中文目标语言不再把汉字静默删除后返回残缺译文；逐段检测到汉字时以更严格提示重试。
- 逐段比较原文与译文中的阿拉伯数字集合。新增数字或遗漏原文数字都会重试，防止容量、尺寸、价格和日期被模型擅自改写。
- 每段最多两次；仍不符合目标语言或数字保真要求时明确失败，调用方收到错误，不把局部结果当成完整翻译。
- 中文目标语言继续允许汉字，现有语言别名和 11 种目标模板不变。
