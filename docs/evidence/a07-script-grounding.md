# CNT-002 商品话术事实门禁

验证日期：2026-11-14

## 实现

商品直播话术生成后、返回调用方前增加可执行事实检查：

- 输出中的阿拉伯数字必须出现在输入商品资料中；新增数字视为无依据事实。
- 输入没有任何货币表达时，输出不能出现人民币/美元/欧元/英镑符号或常见中文价格单位。
- 首次不合格进入现有第二次生成机会；两次仍不合格则明确失败，不把内容作为可用话术返回。
- 输入本来包含的容量、尺寸、价格等数字与货币表达保持允许。

该门禁不试图用规则替代人工质量审核；它只拦截能够确定的数字和价格编造。

## 自动化证据

- `tests/test_structured_speech_grounding.py`：3 项通过。
  - 编造 `99` 个优惠名额后重试，第二次只使用输入中的 `530` 毫升并通过。
  - 无价格输入却生成“九十九元”，两次后明确失败。
  - 输入包含 `530毫升` 和 `99元` 时原样通过。
- `generate_script` 既有恢复契约继续覆盖空结果、部分商品失败、全部失败和异常输入。
- 恢复基线五关全部退出 0。
