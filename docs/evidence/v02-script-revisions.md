# V02-03b 话术载入修改与来源保留

2026-11-10复核V02编辑要求发现，现有记录区只能阅读，缺少将已有生成稿载入表单修改的入口。因此补齐此项，未以新增人工话术代替已有话术编辑。

页面每条记录支持“载入修改”，保存创建新稿，保留原稿和parent_script_id；历史稿载入时提示按当前商品事实修改。修改稿绑定当前商品快照，原稿必须存在且属于同一商品；跨商品原稿引用在服务端拒绝。当前并不将保存动作标为审核通过，也不触发播放。

SQLite结构版本升级至2，事务内增加可空parent_script_id外键；原有记录默认NULL，其余数据保持。迁移测试用原版本1结构、真实旧商品及话术记录验证升级、修改和重开，未以空数据库替代历史数据迁移。

9项数据层、17项控制台、9项LLM协议/进程、3项真实验收工具测试通过，共38项；JS语法检查通过。覆盖原稿保留、历史稿按当前快照改写、跨商品引用拒绝、原有模型生成及取消回归。

本机浏览器使用原真实验收数据库的隔离副本logs/validation/v02-revision-ui，访问5208。载入版本3青瓷杯真实生成稿，删除“装水泡茶都够用，摆桌上也清爽”等措辞，按530毫升/青瓷/青绿色事实保存，页面显示“当前·修改稿”，原稿仍显示。退出进程42300码0；独立进程重开确认杯子4条记录、最新parent指向此前真实生成稿、source=manual；桌布仍1条。截图revision.png及数据库仅在本机忽略目录。

这属于开发验收中的代理编辑，不冒充用户对文案风格的人工认可。V02-05c内容质量问题仍待用户回复，V02整关未放行。

## V02-03c 当前话术选择

补齐话术本身的持久选用状态，非仅商品选中状态。数据库版本3增加按商品关联话术的script_selection表，保留之前商品/话术/来源；显式选择必须属于同商品且输入版本为当前商品版本。商品修改后旧选择不会再作为有效选用稿返回，历史稿直接选用返回409；先核对并保存修改稿才能重新选择。生成成功不自动选用，选择也不启动播放。

本轮10项数据层、17项控制台测试通过，含版本1迁移回归、跨商品选择拒绝、选择重开、商品编辑使选择失效及修改稿重新选择。JS语法检查通过。本机浏览器在5208选择已修改的版本3稿，刷新后显示“当前·已选用·修改稿”；历史版本无直接选用按钮。退出进程80557码0，独立进程重开确认选用ID为修改稿ID，桌布选用状态仍空。截图selected.png仅保留本机。内容风格确认仍待用户，不将代理点击选择作为用户审核批准。
