# V02-02 持久化验证

日期：2026-11-10。实现：scripts/product_store.py。Python标准库SQLite，不引入数据库服务，不读取/修改原运行包或旧用户项目。

商品包含稳定UUID、原product_index（保留字符串/整数形式）、整数化唯一编号、标题、商品信息、extra扩展字段和递增版本。编号8与字符串008视为同一原编号，创建冲突明确报错；排序不使用编号作下标。编辑必须带预期版本，以单条条件更新实现并发冲突检查；事务失败回滚。

话术保留独立ID、所属商品ID、商品输入版本、完整不可变快照、文本、来源和创建时间。入库在IMMEDIATE事务内比较当前商品和输入快照；商品已编辑或快照被拼接到其他商品时拒绝，保留已有记录。当前保存的是人工话术或调用方提供的LLM结果，尚未调用真实LLM。

选中商品通过外键独立保存。extra未指定时编辑保留旧值；调用方显式提供对象时整体替换，原项目导入尚未实现，因此仅证明扩展字段容器往返，不宣称历史项目全部兼容。版本1数据库拒绝未知user_version，损坏数据库交由上层显示错误，不自动新建替代或吞掉错误。

验证命令：

```powershell
python -X utf8 -m unittest discover -s tests -p test_product_store.py -v
```

本机实际使用Python3.10，7项通过：

- 中文、稀疏编号008/3、嵌套未知字段、选中项与话术快照通过独立Python进程重开验证。
- 数字等价编号冲突不插入第二条。
- 空标题/商品信息、非法编号、bool、浮点、越界编号拒绝，不留下商品。
- 两线程两数据库连接并发提交同一版本，仅一个成功，最终版本2。
- 商品修改后旧快照生成结果拒绝，既有话术不变。
- 拼接另一商品ID的快照拒绝；按商品读取话术不串数据；不存在的商品不能选中。
- 更新撞号回滚；空话术不入库。

范围：V02-02数据层通过。页面编辑V02-03、显式LLM调用V02-04、真实生成及整关V02-05尚未通过。历史话术保留其输入快照，后续播放选择必须检查版本；存储不等于允许过期话术直接播报。
