# V05-03b-03 连续音画输出

状态：连续输出功能实测通过；V05-T1 时间指标未通过，V05 整关未放行。

## 实现

- 常驻形象模型生成待机及整句口型，统一累计采样时间轴，原始帧额度维持8帧。
- PCM文件按样本连续消费，允许跨句边界，不逐句补齐或截断。模型及音频双确认后才删除自有快照。
- 一个带明确PTS的NUT流送入一个FFmpeg NVENC/AAC进程，连续输出MPEG-TS；验证后的MP4仅用于媒体检查，不参与实时拼接。
- 启动8帧为显式预缓冲，不计稳态迟到统计。没有声音设备或直播平台的端到端完成结论。
- 每条语音交接原先四次完整扫描形象，750帧单次约1.12秒。改为启动完整校验、运行核对清单身份、模型逐帧校验实际读取的JPEG及位置文件字节，避免重复扫描而保留模型输入完整性。未使用文件不在热路径反复扫描。
- 补齐启动前停止和启动等待中的取消，失败报告保留注入及部分完成记录。
