# CNT-010 一键成片检查点与回滚

验证日期：2026-11-14

## 本轮实现

- 请求指纹由项目、有效文案和调用参数稳定生成；音频步骤把同值写回项目后指纹不漂移。
- 同一项目使用进程内可重入锁，避免两次页面点击并发覆盖相同固定产物。
- `audio → video → subtitles → finishing → publish_meta` 每步开始、成功和失败都会立即写入 `one_click_pipeline`，不再只在全部成功后记录。
- 恢复时只复用“检查点已完成且对应产物仍存在、非空”的步骤；文件缺失会从该步骤重新执行。
- 每一步执行前备份其已存在的固定输出。失败时恢复旧文件、删除本次新建的半成品；回滚不完整会明确返回并禁止声称可恢复。
- 同一指纹全部完成后再次调用返回 `already_complete`，不重复调用 TTS、GPU 或后期服务。
- 步骤结果持久化时去除重复的大型 `project` 快照，保留状态、路径和错误摘要。
