# V02-03 编辑界面/API验收

日期：2026-11-10。数据位于独立忽略目录logs/validation/v02-ui，只有本次手工创建的测试茶杯和测试毛巾。没有读取原商品项目或调用LLM。

## 实现

本地页面接入商品新增、编辑、选择、重读及人工话术保存。读取接口/api/products、/api/scripts，写入沿用Origin/Host/会话令牌校验。商品更新按版本，过期编辑或话术快照返回409，数据库错误返回503，不自动清空数据。用户文本用textContent渲染。请求上限1MiB，可承载中文商品信息与话术；界面/数据层仍有各字段限制。

商品编辑后，旧话术显示输入版本及“历史”，不冒充当前话术。保存话术时若表单与已保存商品不一致，明确要求先保存商品。每次保存话术均提交所属商品完整快照；服务端再次验证，不能靠界面变量单方面保证归属。
