## 本轮发现并修复

使用独立媒体 Python 直接运行 `python scripts/console_package.py deploy` 时，解释器环境中的第三方同名 `scripts` 包可能抢先解析，模块形式 `python -m scripts.console_package` 不受影响。入口现会在文件路径启动时显式加入仓库根；同一直接命令复测 deploy 成功。
