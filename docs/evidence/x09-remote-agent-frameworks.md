## 不可让渡的产品边界

即使未来采用某个框架，以下状态仍由本系统唯一持有：商品/话术/音色/形象版本，轮播顺序，直播 session/epoch，接管和恢复，平台评论去重，口播完成记录，失败补偿及审计。外部框架只可承载带版本身份的音频/视频块或远程连接事件，不能自行重试已失效口播、重排商品或成为第二套业务数据库。

所有适配器必须满足：连接与业务 session 一一绑定；断连使未提交输出失效；重连使用新 epoch；背压受本地预算控制；停止后不接受晚到媒体；云端费用、区域、数据留存和凭据分别配置；基础单机直播不依赖外部服务。

## 当前决策

当前目标是本机单路电商直播及原 v122 功能闭合，没有已确认的浏览器远程通话、多房间或多租户代理需求：

- OpenSpline 与 X06/X07 同属新头像候选，且自托管平台边界不同；当前不作为传输层引入。
- Pipecat 会与已有商品轮播、评论回复、TTS 队列和接管状态机重叠；当前不采用。
- LiveKit 只有在明确需要 WebRTC 房间、远程坐席或浏览器双向互动时才有独立价值；当前延期。

因此 X09-02～04 记录为“未触发/不采用当前版本”，不是技术测试通过。恢复触发条件：出现已批准的远程双向互动或多会话需求，并给出并发量、区域、延迟、费用和数据留存约束。届时按 OpenSpline→Pipecat→LiveKit 分别做最小真实连接、断连/重连和取消原型，只选能解决明确缺口的单项。
