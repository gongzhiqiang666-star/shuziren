## G10-01 多店与权限

- 本地账号认证已接入：PBKDF2独立盐密码库、按店角色、内存会话、HttpOnly Cookie、注销/过期/重启及改密/禁用即时失效均有专项和真实 Chrome 证据，见 `g10-local-account-authentication.md`。企业 SSO 与生产身份生命周期仍待试点。

- 店铺工作区隔离商品、经营报表、采购候选、投放方案、配置和资产；跨店已知编号不能读取或写入。
- 兼容单机入口仍可由受控启动器传入 viewer、operator、admin，父进程角色不会被继承；登录保护入口则只使用账号库的按店角色。两种模式的拒绝和允许均写店内授权审计，启动参数账号不冒充登录身份。
- 三个独立店铺的真实 Chrome 页面正确显示店铺、账号和角色；viewer/operator 商品写入被页面拒绝，admin 保存成功，权限审计与三个浏览器动作一致。证据 `logs/validation/g10-managed-roles-ui-01/result.json`。
- 跨店准备模板只保存场次目标、目标人群和本场限制，应用到另一店时保留目标店商品事实；价格、库存、发货、活动、音色、账号和源店商品编号不进入模板。
- 本机两个独立店铺服务与两个 Chrome 页面完成真实跨店操作：一店页面保存模板，二店页面读取并应用；二店商品、赠品活动、库存 88 和次日发货保持不变，共享 SQLite 中不含一店商品、价格、库存或发货信息。结构化报告和页面截图位于 `logs/validation/g10-shared-template-ui-04`。
