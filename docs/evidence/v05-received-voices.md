# V05-04b-04 真实新语音双设备同时接收

状态：两条新语音的实际接收内容和源时间轴同步短测通过；帧连续性未通过，V05整关未放行。

## 实现

- `scripts/received_voice_audit.py` 提供验证专用16位帧编号覆盖与DirectShow同时接收。编号不写入普通产品输出，也不改动送入模型的音频。
- 在连续场次开始后启动摄像头/CABLE共同接收，统一接收墙钟、20ms音频接收缓冲、无额外补帧的passthrough输出，FFV1+48kHz单声道PCM留样。
- 运行中新TTS的完整原始WAV独立重采样后与实际接收PCM做整句相关性核对，阈值0.95；结合该句在场次内的真实起始采样及实际接收到的画面编号，测源时间轴音画偏差。最近参考画面缺失时额外计入40ms/帧不确定性，`绝对偏差+不确定性≤80ms`才通过。
- 这证明源音画时间轴同步，不代替人物嘴形语义、身份保持或人工听感检查。
- 校验脚本显式设备模式与普通编码文件模式分别保留；设备入队事件不伪造截止时间通过。接收异常会将整次状态设为失败，避免此前阶段性成功字段掩盖后续审计失败。
