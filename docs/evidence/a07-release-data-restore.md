# A07-03 受控数据恢复

日期：2026-11-14

## 完成范围

- 新增 `restore-data --root <安装目录> --backup <备份编号>`，只接受工具生成的固定格式编号，不接收任意路径。
- 恢复前逐项验证备份目录、清单版本、文件全集、大小、SHA-256、链接边界及 SQLite 完整性；额外或缺失文件同样拒绝。
- 在修改当前数据前再次生成安全备份，记录于命令返回的 `safety_backup`。
- 先把目标备份复制到安装目录同卷暂存区，再次复算文件全集、摘要和数据库完整性，防止验证与复制之间的变化。
- 保持部署锁及所有托管运行实例锁；直接启动的主店/店铺实例通过数据锁探测，运行中拒绝恢复。
- 当前 `data` 与已验证暂存目录采用同卷目录改名切换；切换异常时将旧目录改回。数据恢复不暗中切换应用版本。

## 验证结果

- 控制台包专项累计 17/17 通过。
- 实际恢复后目标普通文件回到备份内容，恢复前的当前内容存在新安全备份中，`active.json` 保持原版本。
- 篡改备份在任何当前数据修改前被拒绝，当前文件逐字节不变。
- 既有备份、迁移、发布切换及多店锁回归继续通过。
