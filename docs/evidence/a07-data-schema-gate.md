# A07-03 数据架构版本门禁

日期：2026-11-14

## 完成范围

- 源码包清单必须声明正整数 `data_schema`，安装根以原子写入的 `data-schema.json` 记录共享数据当前架构。
- 首次部署仅接受当前工具明确支持的架构；已有安装从状态文件读取，旧安装没有状态文件时从当前已校验发行清单安全推导。
- deploy 和 rollback 的候选架构必须与共享数据一致；没有实现迁移器时明确拒绝跨架构切换，不运行候选健康检查、不备份、更不改版本指针。
- `run` 再次核对当前发行版能否打开数据架构，防止状态文件或版本目录被手工错配后继续启动。
- 每份新数据备份记录 `data_schema`；restore 只允许恢复与当前架构相同的备份。旧版 v1 备份清单缺字段时按 v1 兼容读取。

## 验证结果

- 控制台包专项累计 18/18 通过。
- 构造数据架构 2、候选/当前发行架构 1，rollback 在健康检查前拒绝，run 拒绝启动。
- 构造 v1 备份后把安装状态改为架构 2，restore 在修改数据和创建安全备份前拒绝，当前文件不变。
- 同架构备份、恢复、发布切换、多店锁和既有迁移回归继续通过。

当前没有宣称支持 schema 1→2 的迁移；未来增加架构时必须同时提供有备份、有回滚且经过真实数据恢复验证的迁移器，不能只提高清单数字。
