# V03-04 缓存、变速与异常恢复

2026-11-10，控制台增加自有内容缓存，原AudioCacheStore兼容实现不改。原实现以路径/大小/mtime识别参考音、仅检查输出存在，控制台新层使用音色/参考音/参考文字内容SHA256、文本、语速、语言和引擎文件指纹。引擎指纹覆盖当前配置、GPT/声码器权重、tokenizer及相关Python源码；换模型/代码后应重启worker，不支持模型文件热替换。
