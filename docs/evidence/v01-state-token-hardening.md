# V01 控制台状态令牌收口

日期：2026-11-14

## 问题

控制台前端启动时通过同源 `/api/session` 获取一次随机写入令牌，后续 POST 同时校验 Host、Origin 和 `X-Console-Token`。只读 `/api/state` 又重复返回同一令牌，但前端从未使用该字段。状态探测、诊断工具或日志若完整打印响应，会无必要地扩大令牌暴露面。

## 修复

- `/api/state` 不再返回 `token`，只保留配置、监听端口、直播状态和受管数据目录。
- `/api/session` 启动协议保持不变，不破坏当前浏览器加载和写请求。
- 新增回归断言，连续刷新状态均不得出现令牌，也不得创建配置或直播场次。

## 验证

- 使用真实随包 FFmpeg 执行控制台 HTTP 59 项，全部通过、无跳过。
- `scripts/local-console/app.js` 通过 Node 语法检查。
- POST 的 Host、Origin、令牌以及角色权限既有测试保持通过。

此修复减少只读诊断面暴露，不把本地控制台声明为互联网认证服务；生产多店的认证/SSO 仍按 G10/A07 边界单独验收。
