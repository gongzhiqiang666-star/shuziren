# CNT-008 抖音对标视频提取

验证日期：2026-11-14

## 本轮实现

- 从用户粘贴的分享文案中提取 HTTPS URL，只接受 `douyin.com`、`iesdouyin.com` 及其真实子域，不接受 HTTP、用户凭据或相似恶意域名。
- 下载器保持参数数组调用且设置 600 秒上限；输出文件必须解析到下载工具目录内，禁止借 stdout 指向任意本机文件。
- 只接受非空的 MP4/MOV/MKV/WebM/FLV/M4V，调用随包或 PATH 中的 FFprobe，确认可解码且至少包含一条视频轨，之后才进入 Whisper ASR。
- 项目归档先在同项目内完整准备视频和 UTF-8 文案，再替换 `benchmark` 目录；失败恢复旧目录，不保存半成品项目状态。

## 验证

`tests/test_douyin_benchmark.py` 4 项通过，覆盖分享文案解析、协议/域名拒绝、目录逃逸拒绝、非空媒体选择、视频轨门禁和完整项目目录替换。

本机另用随包 FFmpeg 生成 320×240、25fps、1 秒 H.264/AAC 文件，恢复版 FFprobe 门禁确认视频轨数量 1、时长 `1.000000`。
