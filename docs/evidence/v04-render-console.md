# V04-03：当前话术语音到数字人视频页面

## 实现

新增`avatar_render.py`共享真实离线渲染入口；验证CLI和产品`render_worker.py`都调用恢复版VideoSynthesizer，使用真实WeNet与UNet。页面使用当前商品已选话术生成的成功语音，加当前选用形象，显式点击生成视频；没有自动播放或开播。

`RenderTasks`绑定商品ID/版本、话术ID、音色ID、TTS任务ID、音频SHA及形象ID/素材清单SHA。派发复制已校验语音到自有任务目录，完成前再次校验绑定及产物。取消、选用输入变化、重开未完任务、迟到结果和不匹配路径均不能成为当前视频；旧任务取媒体返回409。结束后清理语音快照和中间视频，成功MP4及任务日志保留于自有render-jobs/UUID。

新增视频预览、生成状态、刷新、取消、输入编辑清理。启动检查期间的取消请求先在页面保留，拿到新任务ID后立即提交取消，避免按钮只能等待启动完成。状态响应代次校验阻止旧轮询覆盖新任务。同一操作内形象完整指纹只校验一次，派发/完成/媒体访问的校验仍保留。重开和退出沿用本实例工作进程及子进程回收。

视频媒体通过流式文件响应和HTTP byte range提供，支持200/206/416、前缀/后缀/开放末端区间；不一次将完整视频装入内存。发送前校验任务、输入、路径和文件SHA；损坏或缺失视频使任务失效。浏览器中断预览不会重复发送错误响应。
