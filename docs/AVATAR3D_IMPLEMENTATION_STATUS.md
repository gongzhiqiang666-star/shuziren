# v0.3 低端 3D 本地预览交付记录

日期：2026-10-31。分支：`codex/low-end-3d-preview`。基于 v0.2 本地工作台的 `644ec6911b955c42b17de8de3fa1b558517b37ba`，新增可独立运行的 `/avatar3d` 质量验证入口。

本版用于回答两个实际问题：目标电脑能否顺畅显示真正的三维人物，以及实际中文声音驱动的观感是否可接受。它尚未把低端 3D 接入自动业务派发或淘宝开播，不能用以下软件测试代替这两个质量结论。原高端路径的历史验证见 [v0.2 交付记录](IMPLEMENTATION_STATUS.md)。

## 已实现

| 功能 | 实际行为 |
| --- | --- |
| 三维人物 | Three.js / WebGL2 加载真实 GLB 网格；固定 CC0 样例或本地自选模型；旋转、缩放、胸像构图、已识别 Mixamo 骨架的自然站姿 |
| 表情与嘴形 | Oculus 15 嘴形、ARKit 兼容映射；嘴唇、牙齿、舌头同步形变；手动嘴形、眨眼、小幅待机动作 |
| 音频输入 | 当前浏览器导入 WAV 或麦克风录音；原始文件 SHA256；不上传音频，不调用付费 API |
| 自动分析 | 固定版本 HeadAudio 声学模型，在本地 Worker 分析实际 PCM；不是文字估时或仅按音量张嘴 |
| 轨道与播放 | 标准音频哈希绑定轨道、Rhubarb 时长校验导入；用音频 `currentTime` 采样，支持播放、暂停、拖动、停止、重播、幅度和时间偏移 |
| 输出 | 纯画面、绿幕、浏览器原生画面加声音录像、WAV/轨道/验证记录下载 |
| 工作台衔接 | 原工作台增加 3D 入口与实际合成 WAV 下载；当前明确采用人工导出/导入 |
| 本地交付 | 带样例的预构建 ZIP；Node 本机静态服务；源码准备脚本、固定下载地址及大小/SHA 检查；许可及逐文件哈希清单 |

## 已实际执行的验证

本轮环境为隔离 Linux、Node.js 24.22.1、Python 3.12，以及真实 Chromium。图形使用 SwiftShader 软件渲染，不能代表用户电脑的核显、独显或可承载路数。

| 检查 | 结果与证明范围 |
| --- | --- |
| 前端测试 `npm test` | 14 个测试文件、78 项通过，其中新增轨道/嘴形采样测试 35 项；含哈希、时长、格式、边界及跳转等 |
| 生产构建 `npm run build` | Vue/TypeScript 检查与 Vite 构建通过；3D 页按路由动态加载 |
| 生产依赖审计 | `npm audit --omit=dev` 当次报告已知漏洞 0；不外推为全部媒体模型依赖审计 |
| 真实人物资源 | 实际 36,815,920 字节 CC0 GLB，SHA256 与固定源一致；8 个网格，约 8.37 万三角形 |
| 真实生产浏览器 | `tests/browser/avatar3d.cjs` 9 组检查通过、退出 0；页面/控制台错误 0、WebGL 上下文丢失 0 |
| 本地分析 | 真实 Worker 对合成 PCM 测试音运行，导出 30 段嘴形及匹配音频 SHA；错误 SHA 被拒绝且保留有效轨道 |
| 原生录制 | MediaRecorder 实际生成 74,700 字节 WebM；浏览器可解码，ffprobe 确认 VP9 视频与 Opus 音频双流。该软件图形环境帧率很低，此结果不证明连续运动流畅度或目标机音画质量 |
| 启动与打包脚本 | Python / Node / Shell 语法与资源检查通过；Windows PowerShell 和 macOS 双击启动未在原生系统实测 |

九组浏览器检查覆盖：固定真实资产、三维渲染与相机旋转、六种嘴形的实际像素差异、本地分析与轨道导出、播放器时间轴、错音频轨道拒绝、纯画面与 Esc 恢复、原生录制与下载、验证记录和错误检查。页面禁止外部网络及业务 API 请求，测试没有使用模型、音频或录像的成功替身。

测试输入为明确的合成音调，不是中文语音或 TTS 成品。浏览器报告和内部截图位于 `test-results/avatar3d/`，不提交 Git。生产服务验证发现并修复了内嵌纹理 `fetch(blob:)` 的 CSP 阻断，修复后完整复跑通过。

CI 已加入同一生产服务上的 3D 浏览器检查、固定资产准备和 ffprobe；远端具体状态以该分支实际 Actions 记录为准，不把旧提交的绿色检查算作本版验证。

## 尚待用户目标机器验收

- **真实观感：**内置模型仍有 CG 感，未作为最终客户形象验收。真实三维不等于真人级外观。
- **中文口型：**上游声学模型用英语训练，中文细分发音未达成准确率结论。轨道哈希只证明声音绑定，不证明嘴形正确。
- **设备性能：**需在用户电脑记录正常观看尺寸下的帧率、录像动态和音画同步；当前软件渲染数字不能用于最低配置采购结论。
- **输入输出：**真实麦克风授权及采集、Windows/macOS/Safari、OBS 原生采集分别实测。纯画面模式需要保留当前页面，不是自动恢复文件的独立 OBS 浏览器源。
- **业务与长时：**低端自动派发、真实 TTS 目标机性能、获准的淘宝实播、8 小时稳定性未验收。

本地步骤见 [AVATAR3D_LOCAL.md](AVATAR3D_LOCAL.md)，固定资产及许可见 [AVATAR3D_ASSETS.md](AVATAR3D_ASSETS.md)。先保留一段实际中文样片和导出的验证记录，再根据看到的具体问题决定形象调校、中文对齐或硬件优化。
