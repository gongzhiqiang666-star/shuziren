# 轻量 3D 本地验证版 v0.3

本包用于在本机检查真实 GLB 三维人物、实际 WAV 驱动的嘴形和浏览器音视频录制。它是入门款的可选形象预览，不替换真人直播链，也不代表 OBS、平台直播、中文口型质量或长期稳定性已经验收。

## 启动

1. 解压 ZIP 并保持 `app/` 与启动文件的相对位置。
2. 安装 Node.js 20.19+/22.12+，推荐 Node.js 24。预构建包不需要 npm、Python、CUDA、数据库或模型服务。
3. Windows 可运行 `start-windows.cmd`；也可在解压目录执行：

```sh
node start.mjs --dir app
```

4. 打开 `http://127.0.0.1:5173/avatar3d`。服务只监听 `127.0.0.1`；端口占用时使用 `--port 5174`。

## 验证步骤

1. 等待内置 CC0 人物加载，拖动旋转并测试闭唇、唇齿、张口和圆唇。
2. 导入最长 5 分钟、最大 32 MiB 的 WAV，或经用户授权后录制最长 60 秒的本机声音。
3. 等待本地 Worker 生成口型轨道，测试播放、暂停、跳转、停止和重播。
4. 使用“录制人物与声音”导出浏览器支持的音视频文件，并导出验证记录。
5. “纯画面 / OBS”只隐藏控制区供窗口采集；它不是独立 WebRTC 输出，也不会自动接入直播场次。

模型、音频与口型分析都留在当前浏览器；页面不上传文件、不调用付费接口。自动轨道使用固定 HeadAudio 声学模型，中文精细嘴形尚未完成人工验收。示例人物只用于技术验证，不代表客户形象或照片级真人感。

用户自行导入的 GLB 必须有合法使用权，且为不超过 80 MiB 的自包含单场景文件，并提供可用 Oculus 或 ARKit 嘴形。当前不加载外部纹理、Draco/Meshopt、FBX 或 VRM 专用表情。
