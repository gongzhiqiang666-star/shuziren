# V05-03a 时间与输出验收协议 V05-T1

2026-11-11，在V05时间/设备验收前冻结。V05-01/02既有结果只证明交接、模型复用与文件，不追认首音或连续输出通过。以下数字是开发目标，失败须保留，不按结果降低。

固定参考：RTX3060、720×1280/25fps、24kHz单声道PCM16、单路；帧缓冲上限8帧、单批合成4帧，语音队列最多4条/60秒，单段30秒内部预算，长语音无损分段。其他配置另列。

| 指标 | V05-T1门槛及口径 |
| --- | --- |
| 输入完整可用→本机首音/首帧 | 模型已就绪、无前序排队的50次新语音，p95各≤1秒；输入点取完整WAV可用，结束点取实际声音/对应画面，编码器写入不算接收端。排队等待和预缓冲另列，不能从端到端数据中删去 |
| 新问题→首音 | 冻结50条不超过60字的中文新问题；模型就绪、一次一路，包含LLM/TTS和调度，p95≤5秒。本机与目标平台各测；平台未接通时该项待验。5秒沿用归档计划初始目标，未因当前数据放宽 |
| 冷启动 | 三次独立进程，首次编译/缓存命中分别记录；每次准备完成≤360秒，未就绪不能标记可实时开始；不混入热态p95 |
| 输出时序 | 至少连续30分钟，实际接收端25fps；每帧记录预定PTS、提交及接收。提交迟到p95≤5ms、p99≤20ms、最大≤40ms，迟到超过5ms的帧占比≤1%。非空闲内容掉帧/重复帧均0 |
| 声画配对 | 闪屏/提示音同PTS标记，实际接收绝对偏差≤80ms；30分钟及8小时首尾漂移≤40ms。元数据/时长差和口型语义分别检查，不能互相替代 |
| 时间轴计算 | 使用整数累计采样数和帧索引，跨句量化余量保留；累计帧边界误差≤半帧（20ms），音频采样不得删除或变速凑帧。极短片段可以不分配新帧，不得吞掉音频 |
| 停止 | 停止后旧场次不发起新输出；阻塞等待可唤醒，设备/编码缓存和已发送平台缓存分别记录。V06接管用例独立执行 |
| 资源 | 每秒记录CPU/RSS/可用GPU与队列；无字段保留未知。30分钟/8小时末段不持续积压，帧/语音缓冲不得越过上述预算；泄漏和磁盘限额在V08实测 |

首音/首帧需要实机可核对标记或回采，软件等待返回、模型推理结束、帧写入编码器只算中间事件。物理声音设备、虚拟摄像头/OBS及平台分别验证。普通队列的预定播放时间不能当新问题收到时间；积压或先前内容必须在报告中可见。

校准先于50条/30分钟正式测试。测试集、环境、冷/热态、测量误差、所有失败和中断须归档。当前只冻结协议，不表示任一设备或性能门槛通过。涉及真实平台的证据按V07形成，未验证项继续保留。
