## 3. 本轮修复的关键集成问题

- 独立输出正确解析后端完整 `/output#token=...` 路径，拒绝外链、查询参数token和不匹配token；管理口令不进入输出页面。
- 真实输出租约必须有视频、音频播放成功与心跳；HTTP协商成功不能单独证明接收在线。
- TTS实际身份无法确认时停止合成/派发；合成期间换引擎丢弃结果，ready任务也不能发送另一引擎的旧WAV。
- UUID大小写写法共享同一会话/店铺锁与取消域，不能绕开派发和停止互斥。
- BGE缓存绑定完整分词配置与真实文件内容；嵌入完成写回前复核当前知识，删除/过期/改文后的迟到向量不能覆盖缓存。
- 实际BGE联调发现附加商品标题会让退货问题偏向产品规格；改为仅嵌入问题，商品和场次用于范围过滤，商品事实独立提供给模型。
- 可选BGE容器的Compose文件列表持久保存在本机配置；诊断从实际后端网络检查TTS/BGE，避免把容器内部地址从宿主机访问失败误报为模型不可用。
- 平台弹卡/上报在持久化request_id、payload与场次epoch保护下执行；接管后的迟到响应保留结果不明，同一编号不重复出站。
- TOP重复JSON键、缺关键价格/库存字段以及无法确认的空TMC结构均明确拒绝，不将缺字段默认成0或成功。
- 人格保存期间锁定表单，任务轮询保留正在编辑的优先级；前端超时与后端总处理预算对齐。

## 4. 到目标电脑上的测试顺序

1. 获取本次分支，用 `scripts/start-local.ps1` 或 `sh scripts/start-local.sh` 启动应用与PostgreSQL。打开 `http://127.0.0.1:8765`，用本机 `.env` 的 `APP_TOKEN` 登录，运行 `python3 scripts/doctor.py`。
2. 无GPU和付费Key也可先测试商品、人格、活动、记忆、模板、审核、回放、费用设置与数据恢复。
3. 配置自己的DeepSeek Key；安装CosyVoice3与授权参考声音，加载LiveTalking/MuseTalk与授权人物素材。BGE可选，原生端口9890，避免与LiveTalking常用8010冲突。
4. 签发独立输出链接，放入OBS浏览器源，验证真实音视频、关闭运营台后的持续输出、打断与恢复。
5. 使用50句口型语料与音画校准工具，检查当前头像的嘴周、闭唇、牙齿、停顿及真实传输偏差；填写质量档案。
6. 配置获准淘宝应用与账号，逐项验证评论、商品、弹卡、上报和实际接收音画；再做8小时负载、断网、模型重启与恢复测试。

完整操作见[LOCAL_TEST_RUNBOOK.md](LOCAL_TEST_RUNBOOK.md)。DeepSeek Key、淘宝凭据与授权素材只在目标环境配置，不能粘贴进仓库或测试报告。
