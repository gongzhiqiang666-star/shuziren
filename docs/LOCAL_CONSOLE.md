# 本地控制台

从仓库根目录使用 Python 3.10 或以上版本运行：

```powershell
python -X utf8 -m scripts.local_console
```

控制台仅监听 `127.0.0.1`，终端打印访问地址。默认端口5158，配置保存在LOCALAPPDATA/Shuziren/console.json。配置目录支持显式指定：

```powershell
python -X utf8 -m scripts.local_console --data-directory logs/validation/my-console --port 5158
```

端口参数仅覆盖本次监听端口；页面保存的端口下次启动生效。资源路径可填写运行包目录或其_internal目录，预检只检查8项必需文件是否存在，不执行商业程序、不修改原配置，也不验证哈希/GPU/模型/平台。

页面支持保存配置、检查资源和重新读取。刷新仅获取配置，不创建或启动直播。异常在页面显示；损坏配置不会被自动重置，可明确填写完整配置后保存修复。请求日志在数据目录console.log，不记录请求体或会话令牌。

“商品与话术”支持新增、编辑、选择商品和保存人工话术，数据保存于同目录products.sqlite3。商品编号可用稀疏整数或整数字符串，不能重复；更改商品会递增版本，已有话术保留原输入快照并显示为历史。保存话术前先保存商品修改；版本冲突时重读并确认后再编辑。商品选择、已保存信息及话术在刷新和重启后恢复。生成按钮已接入显式LLM配置及后台任务；真实模型效果尚待验收，直播播放未接入。

点击“退出控制台”发送经过会话与来源校验的退出请求，服务停止接收请求、关闭端口并释放实例锁。也可在启动终端按Ctrl+C退出。每个数据目录使用操作系统文件锁，不能通过修改端口重复启动同一目录；锁文件保留不代表进程存活，崩溃后操作系统自动释放锁。端口占用时明确失败，不结束占用端口的其他程序。LLM生成使用本实例持有的工作进程，取消或正常退出会终止并回收；直播子进程尚未接入。这里只交付启动准备，尚未接入真实直播；不得将此页验收作为V05～V09通过证据。

验证：

```powershell
python -X utf8 -m unittest discover -s tests -p 'test_local_console*.py' -v
```

LLM配置：在启动服务的本机进程环境设置SHUZIREN_LLM_ENDPOINT（完整chat/completions地址）、SHUZIREN_LLM_MODEL及SHUZIREN_LLM_API_KEY，可选SHUZIREN_LLM_TIMEOUT。不要把密钥写入命令历史、截图或Git。页面仅展示是否配置，不回显密钥。生成中刷新恢复任务状态，不重新派发；取消终止本地工作进程，但不保证远端停止计费。

话术记录可“载入修改”，保存生成新稿并关联原稿，原稿不会覆盖。载入历史稿时须按当前商品事实修正。数据库自动从版本1升级至2，保留旧话术与商品；修改稿来源不能跨商品引用。保存话术不等于审核或播出。

当前商品版本的话术可“设为当前话术”，刷新/重开后显示“已选用”；历史稿不能直接选用，商品编辑会使旧选择失效。新生成稿不会自动选用，选择不会启动播放。数据库当前版本3，迁移保留已有记录并增加选用关联。

“参考音色”支持填写本机音频完整路径、名称及对应文本导入，规范化后在独立目录保存。选择音色可试听参考音，刷新恢复选择。损坏、无声、过短/过长媒体会被拒绝；原参考音或文字被修改时，需重新导入。该处试听的是参考录音；下方“话术语音”提供新文本合成。

麦克风录音入口已实现，实机验收尚未完成：开始录音需浏览器麦克风权限，最长30秒，停止后先试听；填写音色名称和对应文本，再点“保存录音为音色”。放弃不保存，退出/离页会释放轨道；保存失败可重试，原始临时录音处理后删除。录音上限512KiB，实际媒体仍需通过1～30秒、音量和解码校验。

“话术语音”使用当前商品已选话术和参考音色合成，支持语速、状态刷新、取消及音频预览。生成不自动播放；输入变化、音频指纹异常或任务失效会拒绝取音频。正常任务复用worker，取消会回收本实例进程，下次合成需重新加载。可勾选“相同内容复用已有语音”启用经过内容校验的缓存；未勾选会重新推理。听感与多音色能力仍在后续验收。
