# 验收清单

以下项目全部为待执行，不是已通过结果。

- [ ] **真实淘宝接入**：指定账号收到画面 声音和真实评论；权限失败有明确状态。证据：测试场次记录与脱敏日志。
- [ ] **淘宝业务接口**：商品查询、直播详情、商品弹卡和状态上报分别取得目标应用与账号下的真实结果；未获准的能力保持待验收。证据：接口方法、调用时间、权限范围和脱敏结果记录。
- [ ] **动态生成**：现场新问题实时经过DeepSeek 本地TTS和口型输出。证据：请求任务链与接收端记录。
- [ ] **商品事实**：测试集中不播过期价或编造优惠；缺事实转人工。证据：版本及审批追踪。
- [ ] **跨店隔离**：其他商家数据和任务不可被当前身份读取执行。证据：权限与检索测试。
- [ ] **人格与记忆**：同事实不同风格一致；更正与删除后不继续引用旧记忆。证据：回归问题集。
- [ ] **完整打断**：接管后旧批次不能重新形成新的本地输出。证据：迟到结果和重连用例。
- [ ] **资源与持续运行**：计划负载连续8小时，无崩溃或持续队列增长。证据：GPU CPU 内存 帧率和延迟曲线。
- [ ] **首音与同步**：统计接收新问题到第一段可听音频的p50/p95及音画差。证据：本机与平台分别测量。
- [ ] **人物细节与口型**：逐头像完成固定语料、正常观看尺寸和嘴周检查；传输校准与口型语义分别验收。证据：源素材、中间结果、OBS录制和淘宝接收端样片；方法见[画质方案](AVATAR_QUALITY.md)。
- [ ] **断网恢复**：显示消息缺口；恢复时不补播过期内容或重复开场。证据：故障注入记录。
- [ ] **安装与回滚**：干净支持环境可安装；备份恢复及失败升级回滚成功。证据：步骤和版本清单。
- [ ] **成本**：实际tokens 电耗 维护时长和必要平台费用可核对。证据：usage与账单或功耗记录。

## 证据等级

1. 单元测试或Mock，只证明对应逻辑。
2. 本地模型与媒体集成，只证明目标电脑的链路。
3. 真实淘宝账号联调，证明指定账号和路径。
4. 客户试点，记录持续使用、真实成本和维护工时。

每次记录日期、环境、版本、输入、预期、实际、命令退出码与未验证项。
